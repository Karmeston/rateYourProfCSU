# 教务课程目录接入

## 数据范围

本轮接入已脱敏的2026-10-18教务快照：4620条课程大纲目录、72条统计学方案课程、79条执行计划课程。没有读取或复用登录Cookie。另有4701条全校方案索引，只取得名称、专业和年份，不能据此生成课程关联。

对照本机原始HTML重新核对231页、4620行的序号、开课单位、编码、名称、总学时、学分、教学形式，全部一致；72条方案及79条执行计划的课程代码/名称也与原表一致。原始HTML含个人信息，继续由Git忽略。原表学时为空时保留空值，不把实践周数换算成学时。

## 课程身份和分类

- 以课程编码识别课程，名称比较仅消除全半角和空白差异，不按名称合并不同编码。双字母编号、短编号及原始历史编号均保留原文，不凭编号推测类别。
- 同一批出现同码异名、不同开课单位或排除课程时，整组留在报告中；不挑选一条覆盖其余记录。原`180460ZG10`对应三个不同名称，暂不接入。
- 已有同码课程保留原ID、开课单位、类别、隐藏状态和评价。既有无编码同名课程不自动认领新编码，避免把不同课程的评价混在一起。
- 分类只采用同码同名、无待核实标记的大纲明确类别或统计学原方案的明确课程模块。理论课、实验课、必修/选修及代码外形不作为专业课/公选课依据。无明确证据的课程分类为空，仍可查找，并提供“类别待核实”筛选。
- 历史公选课仅确认目录中存在，不生成当前学期的开课记录、平台或学分认定规则。原18门MOOC的学年、平台和学分规则保留。

生成结果为4659门候选：专业课2095、公选课69、类别待核实2495；另有17个编码被排除或暂存待核对。这是新快照内的分类统计，不能与既有目录数量直接相加。

## 方案及来源存储

`academic-latest-plans.json`按学院、专业编码、主辅修类型和专项班型选择最新年份，共548条；同年并列方案保留，不用抓取日期取代方案年份。原教务导出的类别列均为“主修”，部分方案名称却明确为辅修专业或辅修学位，因此按名称单独区分。旧版索引仅保留在采集快照，运行时不加载该完整索引，也不下载重复附件。

统计学原方案没有标明版本，保存`source_year=NULL`。可以通过`program=统计学&planYear=unknown`查找，不套用2024级入学年份或全校索引中的2026版。方案查询依然只返回专业课，未取得课程明细的其他方案不会成为空筛选入口。

新增迁移`0011_academic_catalog.sql`，独立的`course_catalog_records`保存目录来源、原行定位、学分、学时和已取得的方案关联。日期字段为采集日期，年份字段只接受已确认版本。资料来源键为脱敏JSON的规范化SHA-256和原行号，换行符变化不会产生重复。目录来源不写入同学投稿表，不在“学习资料”区域展示。

网站继续按页查询数据库，每页24门；完整JSON仅用于离线整理与维护，不打包进前端。按专业筛选仍只返回当页课程的方案记录。

## 整理、验证及导入

```powershell
node scripts/prepare-academic-catalog.mjs
node --test tests/academic-catalog.test.mjs tests/release-catalog.test.mjs
# 仅维护本地数据库，先应用迁移
node scripts/import-academic-catalog.mjs --persist-to tmp/academic-preview-d1
```

生成器、导入器和发布规划各自负责一件事。导入器先完整校验，再以小批JSON参数执行一个原子batch；冲突会在写入前中止，重复运行不增加课程或来源。线上继续使用`prepare-release-catalog.mjs`对最新备份预演，仅输出新增SQL，不直接连接远程数据库。先核验备份完整性和原表计数，再重放SQL逐字段比较全部旧课程及旧官方记录。

实际发布结果与快照预演一致：新增4077门、4710条目录来源；可见目录4941门，其中专业课2450、公选课85、类别待核实2406。12条既有无编码同名关联留待核对。备份、发布SQL、原始HTML和临时核验日志均不提交Git；最终线上版本与核对结果见[部署记录](deployment-20261012.md)。

## 回退

原始数据接入前的代码标签为`codex/academic-integration-baseline-20261018`（`4bed6a6`）。代码回退不删除新增课程或用户内容；旧Worker忽略新来源表，可以在保留数据的情况下回退界面。已应用迁移不倒退。若需撤销目录发行，按发布报告的新ID范围隐藏新增课程，保留其评价，不整体恢复旧备份。
