# 公选课分类与培养方案提示

实现日期：2026-10-09。基于[官方规则调研](elective-credit-research.md)，保留既有深蓝导航、灰白页面和课程评价入口。本次只修改代码与隔离本地预览，没有部署或修改线上数据库。

## 页面行为

- 选择公选课后显示细分类下拉框：自然科学、人文社科、经济管理、艺术体育、类别待核实。可与关键词、学院、排序和分页组合，详情返回保留条件；切换全部课程或专业课清除细分类。
- 详情显示有来源的学分、类别、适用专业与开课记录。开课记录按学年学期展示，不把历史资料标为持续开设。
- 学分认定入口默认收起，可选择电气工程及其自动化2025版、生物工程2023版、生物技术2023版、环境工程2023版、数学与应用数学强基计划2024版，或“我的方案尚未收录”。只针对选中的方案版本显示要求，分别判断艺术与其他学科门类模块。
- 认定结果只使用明确匹配课程ID、方案ID和模块的规则。没有证据显示待核实；相反结论并存显示依据冲突，保留双方来源。同学院、类别和课程名称不参与推断；不扩大到选课许可、毕业总学分、绩点或成绩有效性。
- 有2026—2027第一学期网上MOOC开课证据时显示年度限一门提示；展开后可自述是否已修读其他网上MOOC并收到超额提醒。面授、其他学年、未核实学期不套用此通知。
- 培养方案选择保存在当前浏览器localStorage，可选回未选择以清除；MOOC填写只保留在当前详情组件，不发送到服务端。无需账号，不建立长期成绩或收藏页面。
- 使用指南新增默认收起的具体学分问答，直接复用方案数据并逐项链接官方依据。页尾“反馈与支持”提供[GitHub项目](https://github.com/Karmeston/rateYourProfCSU)、[Issue反馈入口](https://github.com/Karmeston/rateYourProfCSU/issues)、反馈所需资料和简短的Star支持说明。

## 数据与依据

`shared/electives.ts`集中定义类别、已有依据的方案要求和年度MOOC规则。方案按专业与版本标识，不把方案年份自动等同入学年。普通方案不能自动套用于强基、卓越等专项班。

新增迁移`0006_elective_guidance.sql`分别保存课程事实、学期层面的开课记录、课程级模块认定。所有已录入记录需要HTTPS来源、来源标题与位置，未知事实保留NULL。独立的教师与历史授课关系继续保留；没有修改已应用迁移或已有评价。

当期18门MOOC原文只写“文化素质类”，因此当前真实课程全部保留细分类待核实，课程级认定规则尚未填入。没有把名称含艺术的课程直接标成可抵艺术学分。两个已有负编号演示课程填有虚构细分类以验收筛选，页面明确标为演示，不能作为真实课程认定依据。

当期名单逐项核对本地官方DOCX`source-f3d02423ef67.docx`，包括分页处重复表头和每条原表行号。导入保留课程代码、名称、学分、开课单位、平台、原学校和通知定位；年度限制另依据官方指南第二部分第3条。

导入器只接受已审核的2026秋季18门名单，先检查同码异名及既有资料冲突，再用一个D1 batch原子写入。重跑不会覆盖现有分类、评价或隐藏状态。真实课程明确使用正编号，避免只有负编号演示数据时SQLite自动生成负编号。CLI关闭远程bindings，只接受本项目内的本地目录。

## 本地准备与验收

当前预览使用`tmp/ui-preview-d1`，地址为http://127.0.0.1:8787。新的本地目录需要先应用全部迁移：

```powershell
npx wrangler d1 migrations apply DB --local --persist-to tmp/ui-preview-d1
node scripts/import-elective-catalog.mjs --persist-to tmp/ui-preview-d1
npm run build:client
npx wrangler dev --local --persist-to tmp/ui-preview-d1 --port 8787
```

`--persist-to`与Wrangler CLI一致，指定父目录；导入器自动使用其`v3`子目录。此脚本没有线上导入开关。真实课程导入已运行两次，第二次新增为0。
