# 教务系统课程数据采集（2026-10-18）

本轮在用户明确授权下，使用其已登录的“中南大学本科教务管理系统（学生个人中心）”会话读取课程数据，作为现有目录的来源补充。**本轮只读查询，未在教务系统中写入、修改或提交任何内容；数据尚未导入网站数据库。**

## 授权与访问方式

- 用户在本机 Edge 中登录教务系统（`http://csujwc.its.csu.edu.cn/jsxsd/framework/xsMain.jsp`，学生个人中心）并授权代理使用该登录会话读取课程数据。
- 代理从该浏览器当前页面的 `document.cookie` 取得本人会话 Cookie，仅保存在本机 `tmp/`（Git 忽略），未写入仓库、未上传。
- 随后以同一会话、同一浏览器 UA 通过 HTTP 只读访问各查询页面；未获取、未保存账号密码。
- 会话 Cookie 会过期；重新采集需用户重新登录后再次提取。

## 数据文件与隐私

- 结构化数据位于 `data/course-data/pending/academic-20261018/`，属待核对资料，未导入数据库、未修改网站目录。
- 原始页面位于 `data/course-data/raw/academic-20261018/`，被 Git 忽略；原始页面含登录学生的姓名与学号，只保留在本机。
- 结构化 JSON 只保留课程字段，不含姓名、学号、成绩等个人信息；Cookie 不写入仓库。
- 数据为 2026-10-18 单次快照，课程大纲与培养方案随学校更新可能变化；导入前需与现有目录按课程编号核对，并按 `docs/major-catalog.md` 的收录标准处理同码异名等冲突。

## 建议的后续步骤

1. 用课程编码把 4620 条教学大纲目录与现有专业目录（840 门候选/线上 846 门）比对，找出新增编码、学分或名称差异，形成候选清单。
2. 对与现有目录匹配、或属于缺口专业的课程，按需采集 `/jsxdg_xq` 大纲详情（含教学内容与考核方式）。
3. 培养方案课程明细与其他专业方案需要更高权限（教师/管理员）或学校另发正式文件，学生账号无法获取；可继续通过公开的培养方案 PDF 渠道补齐。
4. 如用户愿意提供有权限的账号或导出文件，可再核对全校开课总表；本轮未尝试绕过权限。

## 回退

本轮对教务系统只读，无回退操作。仓库侧新增内容为 `data/course-data/pending/academic-20261018/` 下的数据文件与本说明；删除这些文件即可回到采集前状态，不影响网站与线上数据库。
