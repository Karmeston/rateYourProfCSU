冷缓存下，首页列表也与专业选项解耦，列表只查分页与课程总数。专业选项故障不会连带中止课程列表请求。

详情及评分表单、使用指南和教师页按需加载。课程列表缓存仅含公共数据，键包含全部筛选和分页参数；评分列表、投稿和后台不共享缓存。短缓存期间，课程列表的评分汇总可能比详情晚约一分钟更新。错误和空结果不写入列表边缘缓存。精简的课程详情请求不读取官方材料；旧 API 保持兼容。

仍需留意：任意子串查询冷缓存仍要扫描课程候选；评分优先排序需要汇总公开评价；专业和学院选项的冷缓存仍需聚合。后台统计和评分互动目前保持在各自接口，没有加长缓存，也没有移除现有功能。流量统计每次记账仍有写入成本；若用量再次接近额度，优先看 Cloudflare 的读取和写入指标，再决定是否为搜索加索引或调整统计频率。

## 11 月 15 日：公共接口额度保护

课程及教师 API 先按网络做短时限流。对需要访问 D1 的请求，再由 SQLite Durable Object 原子地扣减网络和全站当天预算；这一步不访问 D1。仅使用 Cloudflare 提供的地址，IPv6 按 /64 归组，日计数只保存带密钥派生的标识。超限返回 429 和重试时间，计数服务异常时不放行。

全站通用目录、按专业查课、筛选选项、详情及评论读取、互动写入和流量统计分别计数。公开列表和选项命中缓存不扣日预算；普通关键词搜索按估算权重单个网络每天可执行 20 次冷查询，按专业的低成本查课使用独立额度。流量统计也单独限额，达到上限只影响后续统计。办公室或校园出口共享网络时会共享网络限额。

读写权重基于当前数据规模，属于服务预算，不是 Cloudflare 账单的精确上限。导入、迁移、后台任务和账户内其他服务不经过该保护；以后大批发布前须估算计费写入，包括索引维护。预算保护能把异常请求限制在对应功能里，不能保证流量暴增时各功能永不降级。生产验证只做少量正常读取，边界和并发测试使用本地库。

## 静态查课

从已核验的线上快照导出 12,626 门可见课程和 398 个专业或班型。以 Vite 内容指纹资产发布，原始 885,031 字节，gzip 约 184 KB（Node zlib 实测）。浏览器只下载一次快照，之后关键词、专业、版本、类别、排序和分页都在本地处理。新版课程广场不发送 PV 事件，以免纯查课触发统计写入；详情和其他页面的统计不变。旧目录 API 仍受原数据库预算保护，也可用于本地开发。

只有选择按评分或评价数排序时，浏览器才请求固定的公开评分汇总。该汇总短缓存，失败时仍显示课程；详情的评分提交、修改、撤回和互动仍走原接口。课程目录更新需重新生成静态资产并发布，流程见 README。公开快照不含历史评价、认证信息、隐藏课程或原始来源。
