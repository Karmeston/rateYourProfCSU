# 管理后台

后台入口：[管理后台](https://rate-your-prof-csu.karmeston.workers.dev/#/admin)。普通导航不增加管理按钮。学生仍使用匿名访客Cookie，不需要账号；管理员使用独立口令和管理Cookie。

## 配置与登录

先应用迁移`0010_admin_traffic.sql`，然后初始化口令：

```sh
# 本地：追加配置到被Git忽略的.dev.vars，保留已有访客密钥
node scripts/setup-admin.mjs --local
# 线上：使用已有Wrangler账户权限，把独立随机配置写入Cloudflare Secret
node scripts/setup-admin.mjs --production
```

初始口令分别保存在本机`tmp/admin-local-password.txt`和`tmp/admin-production-password.txt`，不输出到终端、不提交Git。线上恢复材料保存在`tmp/admin-production-bootstrap.json`，同样属于私密文件。初始化检测已有文件和管理员配置，拒绝覆盖；部分失败时先核对线上Secret名称，再用原恢复材料补齐缺失项，不重复初始化。生产部署不复制本地口令，不更换现有`VISITOR_SECRET`。

管理员口令仅在登录时传入服务端，服务端保存PBKDF2-SHA256口令哈希（随机盐，100000次迭代）。签名密钥独立保存，前端不包含Cloudflare账户凭据。实现使用[Workers Web Crypto](https://developers.cloudflare.com/workers/runtime-apis/web-crypto/)；管理会话最长8小时，HTTPS Cookie具有HttpOnly、Secure、SameSite=Strict和`__Host-`前缀。会话同时在数据库登记，退出后即使复制旧Cookie也不能继续使用。更换口令哈希会使已有管理会话失效。

需要更换口令时生成新的随机口令与哈希，经Wrangler的`secret put ADMIN_PASSWORD_HASH`交互输入更新；不要把明文口令作为命令行参数或提交到配置文件。`ADMIN_SESSION_SECRET`保持稳定，除非需要撤销所有管理会话。管理写入严格检查同源Origin和JSON格式，登录每网络地址每分钟最多5次，审核每管理会话每分钟最多60次。缺少密钥或绑定时管理接口拒绝开放。

## 流量与概况

展示今日、近7天或30天的页面浏览量（PV）、每日趋势、页面分布、热门课程，以及待审资料、评价和举报数量。统计按北京时间自然日计算，从本版本上线开始，开始记录前的日期显示“—”。PV不是独立访客人数，也不保证是真实人数；网络失败、浏览器拦截、自动化访问及共享校园网络限流会影响结果。

前端仅上报页面类型与公开课程/教师编号，不上报搜索词、完整网址、正文或访客身份，管理页面不计入。尊重浏览器Do Not Track设置。服务器仅存每日汇总和短期随机去重编号，IP只作为加盐哈希后的限流键，不写入统计数据库。相同事件重试不会重复累加；筛选和分页查询的变化不单独计数。

汇总保留180个自然日，去重编号保留今天和昨天。每日UTC03:17定时清理，同时删除过期管理会话；不触碰课程、评价、资料、举报和审核日志。统计接口需要管理会话，响应不缓存。轻量表格和CSS条形图不引入图表依赖，后台代码只在访问后台时加载。

## 审核与举报

资料、课程/教师评价、课程/教师回复和举报分开管理，支持状态筛选、正文或课程名搜索、20条分页及刷新。待审队列排除作者撤回和已隐藏课程；全部状态可查阅历史，作者撤回的内容不能在网页中批准或恢复。来源链接、学期、教师和评分与正文一起显示，不公开匿名访客编号。

处理举报时展开原内容，核对后可直接隐藏原记录，再把举报标为已处理或不采纳。只处理举报不会自动隐藏原内容。每次操作必须填写理由并带当前版本，版本过期要求重新核对；状态修改与审核日志原子提交。相同操作编号的原样重试不重复处理，不覆盖作者后续修改或撤回。

操作日志记录对象、动作、理由、时间、网页/命令行来源及处理后版本。旧日志保留并显示历史记录。网页后台和`scripts/moderate.mjs`共用`src/moderation.ts`，避免两套审核规则；已有显式`--remote`命令继续可用。当前是单维护者口令，不提供多人角色、批量删除或学生登录。

## 模块与回退

`src/admin-auth.ts`负责会话与登录，`src/admin.ts`负责管理路由，`src/admin-content.ts`和`src/admin-overview.ts`分别查询内容和概况；`src/traffic.ts`接收汇总并清理过期记录。前端后台、队列、概况及请求分别位于`web/admin*.tsx`，统计上报在`web/traffic.ts`。新增数据库迁移只追加，不修改已应用文件。

代码基线为`codex/admin-baseline-20261014`（`d0e5fa5`）。`0010`为兼容的增量迁移，保留原内容和日志。上一生产Worker`33b0dd6d-666b-48fe-b960-822d909c51b0`识别资料撤回字段，代码回退到此版本会停止后台与新PV统计，但保留现有数据。不要回退到更早、忽略作者撤回的版本，不倒退迁移或用旧备份覆盖后续用户写入。发行和备份核对见[部署记录](deployment-20261012.md)。
