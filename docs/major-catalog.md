## 收录标准

- 在官方大纲及培养方案中找到同码同名记录。类别由大纲明确填写；若大纲未填写类别，必须由近期方案原表的类别列明确标为学科/专业教育课程，不根据名称或代码推测。
- 方案主体为2023版及之后；计算机学院额外保留2018版方案，其中106门目前只有历史方案交叉证据。版本原样显示，专项班、国际班名称保留，不替代普通班。
- 原记录没有待核实标记、未解决的同码异名或代码异常。大纲资料学院只有一个明确单位；“医药信息系学院”等尚需校正的采集标签暂不采用。
- 专业内“选修”仍是专业课，不归公选课。沿用思政排除规则。同名不同代码分别保留，未知代码的既有同名记录不自动合并。

大纲来源涉及20个学院/教学单位（含历史名称），不是当前20个学院的完整开课目录。713门有2023版或之后方案证据，其余106门保留计算机学院2018版证据。160个候选存在名称/原记录待核实问题，1305个未取得本批要求的类别交叉依据，暂不导入。具体计数见`data/course-data/major-catalog-report.json`。

124份原文件SHA-256已与采集manifest比对。28份PDF中的728条记录逐行核对原表课程代码、名称、必选修属性和学分；自动核对使用桌面自带Python的pdfplumber。另渲染抽查人工智能、矿物加工、冶金、地理信息科学和资源勘查工程方案原表，确认跨行名称和小数学分没有错位。其他DOC/DOCX来源使用原有提取记录交叉核对和原文件校验，尚未逐条人工重审全部大纲。

## 数据和页面

`major-catalog.json`是可复现的筛选结果，源文件的标题、网址、版本、SHA-256集中存放，课程保留每条材料的原名、专业、学分、必选修属性和定位。

既有迁移`0007_course_materials.sql`保存版本化的官方课程元数据。课程列表仍按课程ID汇总评价，不把不同方案的学分压成单值。卡片仅显示课程名称、类别、学院、代码和评分。2026-10-15按产品用途调整：详情移除官方大纲及逐条方案区块，也不再显示大纲学院年份；这些记录保留在数据库/API供目录筛选和维护核验，不属于学生学习资料。当前开课学院未核实的情况不由资料名称自动推定。

详情“学习资料”仅展示经审核的同学投稿，例如往年试卷、复习笔记、作业参考链接及考核经验；无投稿时显示真实空状态。官方方案记录用于“按培养方案专业找课”，可能包含辅修课程表，不承诺个人选课资格、毕业学分归属或当期开课。

导入器先验证全部来源及课程身份，再使用一个D1原子batch。已有ID、评价、学院和隐藏状态保留；既有同码异名或资料冲突会中止。无代码同名记录返回人工核对清单。SQL每条最多96个绑定参数，真实课程使用正编号，重复导入新增为0。本地D1目录校验及远程bindings禁用由两个导入器共用`scripts/lib/local-d1.mjs`。

## 本地复现

python scripts/prepare-major-catalog.py
# 用包含pdfplumber的Python执行，默认系统Python不一定有此依赖

python tests/course-extraction.test.py

node scripts/import-major-catalog.mjs --persist-to tmp/ui-preview-d1
npm run check
npx wrangler dev --local --persist-to tmp/ui-preview-d1 --port 8787
