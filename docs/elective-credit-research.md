# 公选课分类、学分认定与功能建议

核查日期：2026-10-09。本次整理官方规定与已有采集资料，未修改网页、未导入课程、未修改数据库。

## 已确认的事实

| 问题 | 官方依据与结论 | 适用范围 |
| --- | --- | --- |
| 公选课有细分类吗？ | [全校性选修课管理办法](https://gip.csu.edu.cn/info/1020/1148.htm)列举自然科学、人文社科、经济管理、艺术体育等类型；已有[2016版大纲](https://bksy.csu.edu.cn/info/1272/3699.htm)也有这些分类。 | 2013办法、2016课程资料。四类可作为目录整理依据；当期课程的类别仍须逐项核实。 |
| 毕业只检查公选课总学分吗？ | [电气工程及其自动化2025版培养方案](https://see.csu.edu.cn/info/1126/1308.htm)“七、课程体系”要求文化素质类至少6学分，其中跨学科门类课程4学分、艺术课程2学分。[生物工程2023版方案](https://mpb.csu.edu.cn/info/1043/3571.htm)的[PDF附件](https://mpb.csu.edu.cn/__local/6/F3/53/9130454FC207AFD31EBCA5B6B1E_FAF76F09_DF087.pdf)第8页要求、第9页备注也有相同结构。 | 已核实的两个版本、专业。不能直接扩展为所有年级、专业或专项班的统一规则。 |
| 本学院开课一律不计吗？ | 没有找到覆盖全校、所有年级的此种统一规定。已确认的近期方案要求跨学科门类；[2013年选课通知](https://bksy.csu.edu.cn/info/1058/2122.htm)还限制与本专业相近的课程。 | 同学院、同学科门类、内容相近是三个不同条件。院级补充限制需另收正式依据。旧通知不能独自证明当前仍采用同一限制。 |
| 课程自身有适用专业吗？ | 2016原始大纲中，“基础会计学”（1-07）的适用专业排除经管类，“金融学”（1-09）排除经济管理类。 | 历史课程适用性证据，不能直接当作2026开课限制。它证明仅判断开课学院不够。 |
| 艺术体育类都能抵艺术学分吗？ | 同一2016大纲把“足球”（3-05）、“篮球”（3-06）列入艺术体育类。 | 分类包含体育，不能据分类自动认定艺术学分；需要课程级艺术认定依据。 |
| 网上MOOC有没有额外限制？ | [2026—2027学年第一学期MOOC指南](https://oa.csu.edu.cn/con/PDFPage?JLNM=C2A7465AF8944A2D8B8BBD47419A99D1&YWMC=ZNDX_ZHBG_GGTZ)第二部分第3条规定每学年限一门网上MOOC公选课，超额课程成绩无效；指南还说明不参加个性化选退课。 | 通知落款2026-07-08，只适用于其所述网上MOOC，不据此限制全部公选课数量。 |

“不计入跨学科模块”“不能满足艺术模块”“不计毕业总学分”“选课受限”“成绩无效”必须分别表达。当前证据不足以把前两项推断为不计任何学分，也不足以推断绩点或推免成绩计算方式。

不同版本要求可能变化。学校[2012版方案](https://bksy.csu.edu.cn/_mediafile/bksy2/2013/01/09/2nv19p3263.pdf)曾出现8学分要求，因此产品必须绑定培养方案版本，不能只用当前年份或学院名称；未核实的版本显示未核实。转专业、强基、卓越、国际班和学分替代规则分别保留，不能套用普通班规则。

## 本地核对与数据缺口

- 当期18门MOOC：`public-electives-current.json`全部只标为“文化素质类”，目前没有独立的四类字段，也没有课程级艺术学分认定字段。不能仅凭名称、开课学院或代码前缀自动确认为艺术课程。
- 历史216门：原分类文字中155条可初步对应四类（经管12、人文社科65、艺体25、自然科学53），61条文字笼统、缺失或其他口径。这里是原文字匹配统计，尚不是完成审核的当前分类。
- 大纲已经保留`applicable_programs_raw`，可以继续整理课程适用性，不必从零猜测限制。原始学院也可能是来源单位，并不等于实际开课学院。
- 已提取的70份培养方案以课程表为主，学分要求、备注与“其他说明”尚未结构化。普通专业、年级、专项类型的覆盖仍不完整，尚无完整的院级例外名单。
- 2026 MOOC通知来自已下载的官方原文件`data/course-data/raw/public-elective-guide-2026-autumn.pdf`，SHA-256与manifest记录一致，正文第2页核实年度限选要求，第5页核实落款。该PDF在本机可读，但本次网页工具无法重新读取OA入口；没有把访问失败解释为规定失效。
- 2016大纲原文件`data/course-data/raw/public-electives-2016.docx`：零起始段落1299附近为基础会计学及适用专业，16173附近为足球及艺术体育类别；与已提取记录一致。原始大文件继续按现有规则忽略，不复制提交。

## 建议先做的功能

### 1. 公选课类型筛选与必要信息

在现有“公选课”筛选下增加一个紧凑的类别选择：经济管理、人文社科、艺术体育、自然科学、待核实。卡片或详情显示已确认的类型、学分、线上/线下；艺术模块资格另行标识，不由“艺体类”推导。类别未知的课程仍可查找。

课程存在、当前学期开设、适用于某专业、计入某学分模块是不同事实，应分别保存；2016资料不能给课程打上“本学期开设”标签。

### 2. 按专业与培养方案显示认定提示

在公选课页面提供可选的“我的培养方案”选择，按学院缩小专业范围，再选入学年级/方案版本、培养类型；不收集姓名学号，不要求登录。学院只是检索入口，实际判断绑定专业方案。

详情提供简短结果，例如“可用于艺术模块”“不满足本方案跨学科要求”“按该通知限制选修”“规则待核实”，附具体原因、适用范围和官方来源。未取得个人方案或课程认定依据时只显示已确认事实，不能给出肯定的可计结论。仅凭同学院可以提示核实，不能自动判为无效。

每个模块单独判断，不把所有认定压成一个`is_eligible`布尔值。来源冲突时展示冲突并待核实，不自动采用最新网页覆盖旧年级方案。

### 3. MOOC年度限选提示

只在网上MOOC课程详情内显示年度限一门的简短提醒、适用学年和来源。可提供本次选课时的“本学年是否已修网上MOOC”选择，回答已修时显示成绩无效风险；该输入是用户自述，不冒充教务记录，也不扩大到面授课程。

### 后续可选：一次性的学分缺口计算

规则覆盖充分后，允许输入已获认定的艺术/跨学科模块学分，返回尚缺数量和对应筛选入口。只处理本次查课需求，无需建立长期关注、收藏或成绩管理页面。源材料未确认学分能否跨模块重复使用时，不自动重复分配同一课程学分。

## 实施所需的最小数据结构

| 数据 | 必要字段 |
| --- | --- |
| 课程事实 | 代码、名称、实际开课单位、学分、类别原文/规范值、官方认定的学科口径、课程级艺术模块认定、适用专业原文、来源与定位 |
| 开课记录 | 课程ID、学年学期、线上/线下、平台、当期开课证据；校外MOOC保留原学校及本校归口信息 |
| 培养方案 | 学院、专业、方案版本、明确适用年级、普通/专项类型、模块要求和其他说明来源 |
| 认定规则 | 适用专业/方案/课程/学年、作用对象（选课/成绩/某学分模块）、条件、结论、依据、证据状态 |

类别体系与跨学科认定口径未必相同，需有正式映射依据；不能直接把四种目录分类等同于学位门类。未知值使用null或待核实状态，不能当成“不允许”。

实施顺序：先核实并整理当期课程分类、学分和学习方式，再做类型筛选；以少量有完整官方规则的专业方案开展认定提示，逐步扩充院级例外。优先上线类别筛选、来源和明确限制提示，完整毕业学分计算后置。
