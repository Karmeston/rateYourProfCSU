# 教务课表与培养方案目录接入（2026-11-07）

11 月 14 日补充：站内按专业查课以培养方案中的课程关联为准，已收录的课程不因缺少分类而从专业列表消失。学生可使用原有匿名评价流程；同一课程在不同方案里保留同一课程编号和评价。未收录的方案可先用课程名称或代码搜索。

本轮在用户授权下，使用其本机已登录的校内网会话（本科教务管理系统·学生个人中心）继续补充课程目录。目标是解决“课程数量不足”和“按专业培养方案查课”两个问题。

## 一、培养方案明细其实可以打开（关键发现）

上一轮把“方案详细”判定为不可用，是因为直接使用了列表页链接里的 `falx=主修`：

- 全校培养方案**列表**（空条件查询）给出的“方案详细”链接形如
  `…/qxpyfa_xq?zy=…&jxp01id=…&jx0301id=…&falx=主修&ndbb=…`，
  访问时服务器返回 `数据操作失败,请联系管理员!`。
- 在“全校培养方案查询”页面按**下拉框逐项选择**（版本、学院、专业、类型）后查询，结果页的“方案详细”链接使用
  `falx=0`（下拉框选项的内部值，0=主修），同一页面即可正常打开，标题为“全校培养方案详细信息”，含完整课程表。
- 也就是说：明细功能可用，只是列表页给出的 `falx` 文本值触发了服务端错误；逐专业下拉查询（用户指出的方式）是可行的。

本轮据此**逐条查询并读取了 548 个最新培养方案**（另加 3 个回退方案，共 551 个），取得 413 个方案的课程表、共 52,467 条方案课程记录；138 个方案详情没有课程表（集中在 2003—2015 年历史方案，以及 2026 版微专业、预科、部分专项班；其中 19 个 2022 年后的空方案已尝试用同一专业较新版本回退，3 个取得课程）。每门课程包含：课程类别/子类别、课程编号、课程名称、必修/选修、学分、总学时、开课学期、学分要求。

## 二、课程名单的补充：各类课表查询·按课程

学生账号还可访问“我的课表 → 各类课表查询 → 按课程”（经 `kblogin` 进入 `/jiaowu/pkgl/llsykb/`）。该页面把**当前学期全部课程名单**（`jx02id`、课程代码、课程名称）内嵌为页面变量，无需逐个点开。

- 逐学期读取页面自带下拉的 **23 个学期（2011-2012-1 至 2026-2027-1）**，每学期约 1,700—2,400 门。
- 合并去重、去除首尾空白并按 NFKC 归一化后得到 **11,347 个课程编码**；同一编码跨学期名称无冲突。

## 三、合并规则与结果

- 课表来源只有代码和名称：**不推测**学分、学时、学院或类别；这些字段留空，站内显示“类别待核实”，仍可搜索。培养方案来源提供学分、学时、学期、必修/选修和课程模块，并按“学科/专业教育课程”模块生成专业课分类证据。
- 合并输入 68,585 行：课程大纲 4,620 + 统计学方案 72 + 执行计划 79 + 课表 11,347 + 培养方案 52,467。
- 生成 **12,624 门候选**：专业课 5,438、公选课 137、类别待核实 7,049；43 门留下未接入（32 门思政等排除课程、11 门同码异名冲突）。
- 培养方案关联覆盖 **395 个专业/班型、4,916 门课程**，“按培养方案专业/版本筛选”不再只有统计学一个专业。
