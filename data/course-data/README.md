# 中南大学课程数据采集结果

采集日期：2026-10-07 至 2026-10-10。已核对18门当期MOOC，并整理819门有大纲、方案交叉依据的专业及学科课程、2240条资料记录，接入隔离本地预览。本轮新增215门课程、575条证据。124份收录原文件SHA-256一致，28份PDF的728条原表记录复核通过。线上目录未修改；历史公选课尚未导入。

- 当期网上 MOOC 公选课：**18 门**，2026—2027 学年第一学期；本校 5 门、校外 13 门，超星 12 门、智慧树 6 门。
- 历史公选课：**216 门**，2016 版，与大纲目录逐项对应；不是当前学期开课证明。
- 培养方案：**73 份有课程提取结果**，合计 **6210 条方案内课程记录**，包含不同版本、普通班和专项班。
- 全部大纲及方案：**11035 条来源记录，5728 个课程候选键**；候选键不等于确认后的独立课程数量。

| major-catalog.json / major-catalog-report.json | 保守筛选后的819门专业及学科课程、原表依据、收录范围、排除统计和复核结果 |
| program-coverage.json | 按学校官方专业目录逐项列出来源覆盖和缺口 |
| manifest.json / sources.json | 来源网址、抓取日期、原始文件路径、SHA-256；包括网页附件和压缩包成员 |
| extraction-report.json / validation-report.json | 每文件提取数量、异常、同码异名和核验结果 |

原文件在 `raw/`，旧 Word 的中间文本在 `text/`，逐源缓存在 `extracted/`。这些体积较大的可重新获取文件保留在本机并被 Git 忽略。

当期名单的类别原文只有“文化素质类”，未据名称或代码推断细分类及艺术学分资格。维护者可用 `scripts/import-elective-catalog.mjs` 导入已核对的18门当期MOOC，仅支持项目内的本地D1目录；先执行迁移。命令、范围与回退说明见 [公选课功能说明](../../docs/elective-guidance.md)。

专业及学科课程须有同码同名的大纲、培养方案交叉依据；类别由大纲明确填写，或在近期培养方案原表类别栏明确标注为学科/专业教育课程。类别缺失、名称冲突的候选不自动导入。方案主体为2023版及之后；计算机学院另保留2018版证据（其中106门尚无近期方案交叉依据），页面显示版本，不标为当期开课。大纲学院可为历史单位，学分按每条方案原表分别保留。标准和导入命令见[专业课目录说明](../../docs/major-catalog.md)。

本轮取得地信学院六个专业的2023版合并方案及生物科学普通班、强基班2025版方案。合并PDF按专业标题切分，去重保留专业、学分和必选修差异。剩余缺口、当前公选课通知的核查结果见[课程资料缺口清单](../../docs/course-data-gaps.md)。报告脚本仅更新结构化统计，不覆盖此处人工维护的导入说明。

## 覆盖范围和限制

以 [学校2026年8月专业目录](https://bksy.csu.edu.cn/jxyz1/xyxl.htm) 的 98 个条目为基准（含停止招生条目），来源覆盖如下：

| 状态 | 专业目录条目数 |
| --- | ---: |
| 已有2023版或之后普通培养方案来源 | 41 |
| 近期只有强基/卓越/国际等专项方案 | 2 |
| 只有历史培养方案来源 | 7 |
| 尚未取得培养方案 | 48 |

资料覆盖不等于完整提取或当前培养要求。大类方案单独保留，没有据此宣称覆盖整个大类的所有专业。强基/卓越方案不能替代普通班方案。

2016 版大纲覆盖当年 33 个学院/教学单位，保留历史学院名称；这不能证明已取得每个专业的培养方案。原始来源学院也不等于实际开课单位。

当期名单目前覆盖网上 MOOC；完整线下公选课目录仍需从本科教务系统的课程目录/开课表取得。最新普通培养方案缺口优先通过各院本科教务办提供的正式文件或学生本人能合法导出的培养方案补齐。不会索取账号密码。

候选中有 308 个键需要核实（含原文代码异常、名称变体等）。来源有更新时按年级和专业选用；同名不同代码不强行合并。

原始资料保留思政及其他学校实际课程证据；按本项目现有规则，思政课程应在导入阶段排除。本次未改线上目录或已有迁移。

## 复现

在项目根目录使用带 lxml、pdfplumber 的 Python 运行（桌面自带 Python 已验证）；旧 Word 解析器固定为 word-extractor 1.0.4：

```powershell
npm install --prefix tmp/course-parser --no-save --package-lock=false --ignore-scripts word-extractor@1.0.4
python scripts/collect-course-sources.py --pending
python scripts/discover-course-sources.py
python scripts/collect-course-sources.py --pending
python scripts/extract-course-data.py --prepare-archives
node scripts/extract-legacy-word.mjs
python scripts/extract-course-data.py
python scripts/report-course-data.py
```

`--pending` 提取复用本地缓存；修改解析器后运行完整提取命令。新电脑下载后，原始内容可能已被学校更新，应检查 SHA-256；清单中的抓取日期不会冒充文件版本。RAR 使用 Windows 自带 tar 流式读取成员，不执行文档。
